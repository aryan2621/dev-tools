# Courier: product

Desktop API client (Tauri + React). Developers compose HTTP requests, group them in collections, switch environments, read responses, and ask a local or hosted AI assistant to explain or draft requests.

- **Mode:** Operate. The user is mid-task, often for hours; scanability and speed outrank expression.
- **Users:** backend and full-stack developers on macOS (also Windows/Linux), keyboard-first, usually dark mode.
- **Principles:** dense and quiet; native-feeling; one accent; never colour alone; every action reachable by keyboard.
- **Not:** a marketing surface, a card dashboard, a chat app skin.
